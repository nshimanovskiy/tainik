Придёт каждому пользователю в чат «Тайник» (служебные уведомления). Одному человеку — кнопка «Написать…» в его строке.

Заблокированные IP

    Заблокированных адресов нет.

    Для каждого устройства хранится последний IP, с которого оно подключалось (его видит и сам пользователь в списке своих устройств). С заблокированного IP нельзя подключиться к мессенджеру и открыть сайт; эта панель остаётся доступной. Удаление аккаунта необратимо: устройства пользователя отключаются и стирают свои ключи, имя освобождается. Официальную галочку видят все собеседники пользователя сразу; у аккаунта admin она стоит по умолчанию. Подписку «Премиум» можно продлить вручную (кнопка в строке пользователя) — например, в подарок или после оплаты, которую не удалось подтвердить автоматически. Поиск «премиум» покажет подписчиков. Текст сообщений серверу неизвестен. Статус «в сети» здесь виден даже у тех, кто скрыл его от собеседников.
