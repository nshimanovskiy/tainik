Заблокированные IP

    Заблокированных адресов нет.

    Для каждого устройства хранится последний IP, с которого оно подключалось (его видит и сам пользователь в списке своих устройств). С заблокированного IP нельзя подключиться к мессенджеру и открыть сайт; эта панель остаётся доступной. Удаление аккаунта необратимо: устройства пользователя отключаются и стирают свои ключи, имя освобождается. Официальную галочку видят все собеседники пользователя сразу; у аккаунта admin она стоит по умолчанию. Текст сообщений серверу неизвестен. Статус «в сети» здесь виден даже у тех, кто скрыл его от собеседников.
