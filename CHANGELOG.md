# История изменений

## 0.6.0

- Ответы на сообщения с цитатой, как в Telegram: наведите на сообщение → ↩︎, или правый клик / долгое нажатие → «Ответить». Клик по цитате прокручивает к оригиналу.
- Удаление сообщений: «у меня» (на всех ваших устройствах) и «у всех» (и у собеседника). Неотправленное сообщение при удалении не уйдёт.
- Статус собеседника: «в сети», «был(а) 5 мин. назад», «был(а) вчера в 21:40»; зелёная точка в списке чатов. Свой статус можно скрыть в меню ⋯.
- Сервер обновляется из GitHub: кнопка Actions → «Деплой сервера» (приватный репозиторий, ключ только для чтения, ключ Actions может только запустить обновление).

## 0.5.0

- Голосовые и видеозвонки один на один.
- Трансляция экрана во время звонка (в десктопе — с выбором экрана или окна).
- Звонок приходит на все устройства собеседника; ответ на одном останавливает звонок на остальных.
- Медиапоток шифруется DTLS-SRTP, а данные соединения передаются через сквозное шифрование — сервер не может вклиниться в звонок.
- История звонков в чате: исходящие, входящие, пропущенные.
- TURN-сервер (coturn) для звонков через NAT: `deploy/setup-calls.sh`.

## 0.4.0

- Первый публичный выпуск десктопной версии (Windows, macOS, Linux).
- Сквозное шифрование: X3DH + Double Ratchet.
- Несколько устройств на аккаунт, привязка по QR-коду или коду из 64 символов.
- Синхронизация отправленных сообщений между своими устройствами.
- Код безопасности (60 цифр) и предупреждение о смене ключа собеседника.
- Ключи и переписка в файле, зашифрованном системным хранилищем (DPAPI / Keychain / libsecret).
