# История изменений

## 0.16.0

- **Блокировка пользователей**: в чате ⋮ → «Заблокировать» (или правый клик / долгое нажатие на чат в списке). Заблокированный не может писать и звонить вам и видит «был(а) недавно» вместо вашего статуса; сам он об этом не узнаёт — его сообщения выглядят отправленными, но не доставляются. Блокировка общая для всех ваших устройств, список — ⋯ → «Заблокированные».
- **Удаление чата**: ⋮ → «Удалить чат» — переписка пропадает на всех ваших устройствах, по желанию и у собеседника. Ключ собеседника сохраняется, поэтому если он напишет снова, чат вернётся, а проверка ключа продолжит работать.
- Блокировку обеспечивает сервер (иначе сообщения всё равно бы приходили), поэтому для неё нужно обновить сервер. Сервер хранит список заблокированных каждого пользователя.

## 0.15.1

- Главная страница `https://ваш-домен/` открывается всегда, даже если вы уже вошли в аккаунт: раньше она сразу перебрасывала в мессенджер. В чаты ведёт кнопка **«Перейти в чаты»** в шапке; если вы уже вошли, она же — главная кнопка на странице. Значок на экране «Домой» и ссылки из уведомлений по-прежнему открывают сразу мессенджер.

## 0.15.0

- **Фото, видео и файлы** в чатах: кнопка 📎, вставка из буфера обмена (Ctrl+V) и перетаскивание в окно чата; до 10 файлов за раз, с подписью и ответом на сообщение. Фото показываются в ленте сразу, видео и фото открываются на весь экран, любой файл можно сохранить (⋯ → «Сохранить файл»).
- **Сквозное шифрование вложений**: файл шифруется на устройстве случайным ключом (AES-256-GCM, частями — подмену, перестановку и обрезку частей видно), ключ уходит собеседнику внутри сообщения Double Ratchet. Сервер хранит только шифротекст и не знает ни имени, ни типа файла; файлы удаляются через `QUEUE_TTL_DAYS` дней. Расшифрованные файлы на диск не пишутся.
- Отправленный файл появляется и на остальных ваших устройствах.
- Новые настройки сервера: `MAX_UPLOAD_MB` (по умолчанию 100) и `MAX_STORAGE_GB` (20). Загрузка идёт частями по 768 КБ, поэтому настройки nginx менять не нужно. В панели администратора — число и объём хранимых файлов.
- Android: выбор файлов из системы и сохранение через окно «Сохранить как».
- Старые версии приложений сообщения с файлами не показывают — обновите приложения.

## 0.14.0

- **Английский язык**: мессенджер (веб, десктоп, Android, iPhone), главная страница, установка на iPhone, трей и системные окна десктопа, уведомления Android и уведомления браузера при закрытой вкладке. Язык выбирается по системе, переключатель — ⋯ → «Язык» и кнопка EN/RU на главной.
- **Синхронизация прочтения**: прочитали чат на одном устройстве — на остальных ваших устройствах счётчик непрочитанных обнуляется и уведомления этого чата убираются. Отметка передаётся зашифрованной только между вашими устройствами.
- Исправлено: на компьютере уведомление о сообщении другому аккаунту не открывало нужный чат и не показывалось при открытом окне.

## 0.13.0

- **Главная страница** `https://ваш-домен/`: что такое Тайник и вкладка **«Скачать»** — файлы последнего выпуска для Windows, macOS, Linux и Android, установка на iPhone и веб-версия. Сайт определяет систему и предлагает нужный файл. Мессенджер переехал на `/app`; кто уже пользуется веб-версией, попадает в него сразу, старые закладки и значки на экране «Домой» продолжают работать.
- **Загрузки с вашего сервера**: он ретранслирует релизы GitHub (`RELEASES_REPO`), поэтому скачивание работает и там, где GitHub недоступен. Поддерживается докачка.
- **Самообновление** десктопа и Android: новая версия скачивается в фоне с вашего сервера; полоска «Доступна версия…» и раздел ⋯ → «Обновления». Windows — тихая установка при перезапуске или выходе, переносная версия и AppImage — замена файла, macOS — замена приложения из .dmg, .deb — открывается в установщике, Android — системный установщик с подтверждением.
- Десктоп ставит обновление, только если выпуск **подписан ключом выпусков** (Ed25519, секрет `RELEASE_SIGNING_KEY`) и файл совпадает с подписанной контрольной суммой: взломанный сервер не может подсунуть приложению свой код.

## 0.12.0

Ставит и снимает администратор в панели («Поставить галочку»), собеседники видят изменение сразу, без перезагрузки. Галочку видно и у тех, кто скрыл статус «в сети».

## 0.11.0

- **iPhone и iPad**: страница `https://ваш-домен/ios` ставит Тайник на экран «Домой» как приложение-закладку — кнопка скачивает профиль с веб-клипом (`/tainik.mobileconfig`, собирается сервером под ваш домен). Открывается без панелей Safari, с уведомлениями и звонками. Нужна iOS 18.4+.
- Веб-клиент готов к запуску с экрана «Домой»: значок 180×180, метаданные iOS, отступы под «чёлку», цвет панели под светлую и тёмную тему. В Safari на iPhone на экране входа — ссылка «Установить Тайник на iPhone».

## 0.10.0

- Панель администратора: **удаление аккаунта** (устройства пользователя отключаются и стирают ключи и переписку, имя освобождается) и **блокировка IP-адресов** (подключения обрываются, новые не принимаются, сайт закрыт; список блокировок с заметками, разблокировка в один клик).
- Сервер хранит **последний IP каждого устройства**. Он виден в панели администратора и самому пользователю в ⋯ → «Устройства».
- Клиент сообщает, если аккаунт удалён администратором или доступ с адреса заблокирован.

## 0.9.0

- **Несколько аккаунтов** на одном устройстве (веб, десктоп, Android) — до 5. Переключение — по нажатию на своё имя слева вверху или ⋯ → «Аккаунты». Все аккаунты на связи: сообщения и уведомления приходят по каждому («bob → alice»), у аватарки — число непрочитанных в других аккаунтах, нажатие на уведомление переключает аккаунт и открывает чат. Ключи и переписка каждого аккаунта хранятся отдельно; «Выйти на этом устройстве» стирает только открытый аккаунт.
- **Панель администратора** на сервере: `https://ваш-домен/adminadminadmin/`. Пользователи, статус «в сети», устройства, IP подключённых сейчас устройств, очередь недоставленных сообщений. Включается паролем `ADMIN_PASSWORD` в `.env` (см. DEPLOY.md). IP хранятся только в памяти; текста сообщений панель не видит.

## 0.8.1

- Звонок можно **свернуть** (кнопка ⌄ в углу, Esc на компьютере, «Назад» на Android) и переписываться в любых чатах, не прерывая разговор. Сверху — полоска с именем и временем звонка: нажатие возвращает к звонку, рядом — микрофон и «Завершить». Видео собеседника остаётся в маленьком окошке, которое можно перетащить. На Android к звонку возвращает и уведомление «Звонок: …» в шторке.
- Исправлен показ экрана: своё превью экрана показывается целиком (раньше обрезалось рамкой 16:10, а при включённой камере его не было видно вовсе), без зеркального отражения, отдельно от камеры. Окошки с видео подстраиваются под пропорции картинки — вертикальная камера телефона больше не обрезается.
- Экран транслируется не больше чем в 1080p (с сохранением пропорций): на мониторах 2K/4K картинка у собеседника больше не «замерзает».
- Если собеседник показывает экран и камеру, нажатие на окошко меняет их местами. Трансляцию можно развернуть во весь экран (кнопка в углу или двойной щелчок).

## 0.8.0

- **Android-приложение** (Android 8.0+): тот же интерфейс и то же шифрование, что в вебе и десктопе, внутри нативной оболочки на Kotlin без сторонних библиотек. APK — в релизе: `Tainik-…-android.apk`.
- Android работает **в фоне без Google**: постоянное соединение с вашим сервером через службу переднего плана (значок «Тайник на связи» в шторке), запуск после перезагрузки. Входящий звонок звонит рингтоном; во время разговора приложение можно свернуть.
- Ключи и переписка на Android зашифрованы ключом из Android Keystore; резервное копирование данных приложения отключено. Интерфейс загружается из APK, а не с сервера.
- Клиент переподключается сразу, когда возвращается сеть или просыпается телефон, и замечает «повисшее» соединение.
- Исправлено: чаты дублировались в боковом списке, пока не выберешь один из них.
- Workflow выпуска называется «Выпуск приложений» и собирает ещё и APK (подписанный ключом из секретов, см. RELEASING.md).

## 0.7.0

- Уведомления о сообщениях и звонках — в приложении и в браузере. По умолчанию без текста сообщения (только имя собеседника); показ текста включается в меню ⋯ → «Уведомления». Клик по уведомлению открывает чат.
- Веб: уведомления приходят и при **закрытой вкладке** (Web Push). Сервер будит браузер через его push-сервис; в пуше только имя отправителя, зашифрованное для браузера. Звонок, который никто не принял, приходит как «Пропущенный звонок». На iPhone и iPad — после добавления Тайника на экран «Домой».
- Десктоп работает **в фоне**: крестик прячет окно в трей, сообщения и звонки продолжают приходить. Значок в трее (открыть / автозапуск / выход), запуск при входе в систему (в фоне, без окна), счётчик непрочитанных на значке приложения. Входящий звонок показывает окно из трея.
- Счётчик непрочитанных в заголовке вкладки.
- Для Windows появилась **переносная версия** без установки: `Tainik-…-win-x64-portable.exe`.
- Выпуск десктопа запускается кнопкой Actions → «Выпуск десктопа» и публикуется сразу (или черновиком по галочке).

## 0.6.0

- Ответы на сообщения с цитатой, как в Telegram: наведите на сообщение → ↩︎, или правый клик / долгое нажатие → «Ответить». Клик по цитате прокручивает к оригиналу.
- Удаление сообщений: «у меня» (на всех ваших устройствах) и «у всех» (и у собеседника). Неотправленное сообщение при удалении не уйдёт.
- Статус собеседника: «в сети», «был(а) 5 мин. назад», «был(а) вчера в 21:40»; зелёная точка в списке чатов. Свой статус можно скрыть в меню ⋯.
- Сервер обновляется из GitHub: кнопка Actions → «Деплой сервера» (приватный репозиторий, ключ только для чтения, ключ Actions может только запустить обновление).

## 0.5.0

- Голосовые и видеозвонки один на один.
- Трансляция экрана во время звонка (в десктопе — с выбором экрана или окна).
- Звонок приходит на все устройства собеседника; ответ на одном останавливает звонок на остальных.
- Медиапоток шифруется DTLS-SRTP, а данные соединения передаются через сквозное шифрование — сервер не может вклиниться в звонок.
- История звонков в чате: исходящие, входящие, пропущенные.
- TURN-сервер (coturn) для звонков через NAT: `deploy/setup-calls.sh`.
